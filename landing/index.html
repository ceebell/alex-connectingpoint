AI อ่านข้อความ รูป และสรุปบิลจาก LINE OA แล้วเตรียมร่างออเดอร์ให้ จับคู่ชุดกับแค็ตตาล็อก เช็คคิวจริง แอดมินตรวจแล้วกดยืนยันครั้งเดียวก็สร้างบิลได้

  • ใช้ LINE OA และ Alex ตัวเดิมได้เลย
  • แอดมินยืนยันก่อนส่งทุกบิล
  • เช็คคิวจริงก่อนรับจอง

ครบทุกขั้นที่แอดมินต้องใช้

ทำงานกับวิธีที่ร้านใช้อยู่แล้ว ไม่ต้องเปลี่ยนรูปแบบสรุปบิลหรือระบบหลังบ้าน

🖼️

สรุปจากรูปและข้อความ

แนบรูปจากแชทหรือจากเครื่องได้สูงสุด 5 รูปต่อร่าง ลบรูปที่ไม่ใช้ได้ทันที รูปแนบเป็นข้อมูลภายใน ไม่ส่งกลับให้ลูกค้า

🧾

อ่านสรุปบิลแบบที่ร้านใช้

ดึงสรุปบิลล่าสุดที่แอดมินส่งในแชทมาให้ AI อ่านได้ในคลิกเดียว แยกรายการ ค่าเช่า ค่าประกัน และคำนวณส่วนลดให้

👤

เติมข้อมูลลูกค้าจากแชท

ชื่อ เบอร์โทร และที่อยู่จัดส่งที่ลูกค้าพิมพ์ไว้ ถูกดึงมาใส่ฟอร์มให้ตรวจ ไม่ต้องคัดลอกเอง

🗂️

เวอร์ชันร่างพร้อมสถานะ

ทุกเวอร์ชันบอกชัดว่าส่งแล้ว ยังไม่ส่ง หรือยกเลิก แก้ไขหรือโคลนเป็นเวอร์ชันใหม่ได้พร้อมตะกร้าเดิม

💳

การชำระและหมายเหตุจัดส่ง

บันทึกรายการชำระเงินและหมายเหตุการส่งชุดไว้ในใบสรุปก่อนส่ง ให้บิลใน Alex ครบตั้งแต่ครั้งแรก

🔐

หลังบ้านเฉพาะแอดมิน

เข้าระบบด้วย LINE Login เฉพาะบัญชีที่ร้านอนุญาต คีย์ API และ token ทั้งหมดอยู่ฝั่ง server ไม่ส่งไปที่เบราว์เซอร์

ความปลอดภัยของข้อมูลและบิล

AI ช่วยเตรียม แต่คนเป็นผู้ตัดสิน

ออเดอร์จริง คิวจริง และสถานะการชำระเงินจริงอ้างอิง Alex เสมอ

  • AI ไม่สร้างออเดอร์เองทุกบิลผ่านใบสรุปและการยืนยันของแอดมินก่อนส่งเข้า Alex
  • ไม่ตัดสินว่าจ่ายแล้วจากข้อความในแชทสถานะการชำระเงินจริงดูจากระบบของร้าน ไม่ใช่จากคำบอกเล่าในแชท
  • ไม่ส่งซ้ำเมื่อผลไม่ชัดเจนถ้า Alex ตอบกลับไม่ชัด ระบบไม่ส่งซ้ำเอง แต่ให้แอดมินตรวจในหลังบ้านก่อน
  • ย้อนดูได้ทุกการเปลี่ยนแปลงเก็บข้อความ รูป และทุกเวอร์ชันของร่างไว้ ตรวจย้อนหลังได้ว่าใครแก้หรือยกเลิกอะไร

เริ่มต้นใช้งาน

เชื่อมระบบที่ร้านมีอยู่แล้ว

ไม่ต้องย้ายข้อมูลหรือสอนลูกค้าใหม่ ลูกค้ายังทักร้านใน LINE ได้ตามปกติ

เชื่อม LINE OA ของร้าน

ตั้งค่า webhook ของ LINE Messaging API ครั้งเดียว ข้อความและรูปใหม่จะเข้าหลังบ้านทันที

เชื่อมบัญชี Alex

ระบบใช้บัญชี Alex ของร้านค้นชุด เช็คคิว และสร้างบิล ข้อมูลและ credentials ของแต่ละร้านแยกจากกัน

ให้แอดมินเริ่มใช้กับแชทจริง

แอดมินเข้าหลังบ้านด้วย LINE ของตัวเอง เลือกแชท กดสรุป ตรวจ แล้วส่ง เรียนรู้ได้ในวันเดียว

คำถามที่พบบ่อย

ก่อนเริ่มใช้งาน

เหมาะกับร้านแบบไหน

ร้านเช่าชุดที่รับจองผ่าน LINE OA และใช้ Alex เป็นระบบหลังบ้านสำหรับคิวและบิล โดยเฉพาะร้านที่แอดมินต้องคัดลอกข้อมูลจากแชทไปเปิดบิลเองทุกวัน

ต้องเปลี่ยนระบบหลังบ้านหรือวิธีสรุปบิลไหม

ไม่ต้อง บิลยังอยู่ใน Alex ตามเดิม และ AI อ่านสรุปบิลในรูปแบบที่ร้านส่งให้ลูกค้าอยู่แล้ว ทั้งรายการชุด สี ไซซ์ จำนวนวัน ค่าเช่า และค่าประกัน

AI จะส่งออเดอร์หรือตอบลูกค้าเองไหม

ไม่ AI ช่วยอ่าน สรุป และเตรียมร่างเท่านั้น การส่งบิลเข้า Alex ต้องผ่านการยืนยันของแอดมินทุกครั้ง

ถ้าคิวชนจะเกิดอะไรขึ้น

ระบบแสดงชุดที่คิวชนให้เห็นในใบสรุป ถ้าร้านยังต้องการส่งต่อ แอดมินต้องติ๊กยืนยันว่าทราบแล้วก่อน จึงจะส่งได้

รูปและข้อมูลลูกค้าจะถูกส่งไปที่ไหน

ข้อความและรูปเก็บในฐานข้อมูลของร้าน รูปที่แนบในสรุปเป็นข้อมูลภายใน ไม่ส่งกลับให้ลูกค้าทาง LINE และหลังบ้านเปิดได้เฉพาะแอดมินที่ร้านอนุญาต

มีหลายสาขาหรือหลาย LINE OA ใช้ได้ไหม

ได้ แต่ละร้านหรือแต่ละ LINE OA ใช้ระบบแยกกัน เพื่อให้ข้อมูล คิว และ credentials ไม่ปนกัน

พร้อมให้แอดมินเลิกพิมพ์บิลซ้ำหรือยัง

นัดเดโมกับตัวอย่างแชทของร้านคุณ แล้วดูร่างออเดอร์จริงที่ระบบเตรียมให้
