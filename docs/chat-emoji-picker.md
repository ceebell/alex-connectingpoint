# แผงเลือกอีโมจิในช่องตอบแชท

กดปุ่มรูปหน้ายิ้มข้างช่องตอบลูกค้าเพื่อเปิดแผงเลือกอีโมจิ ใช้ได้ทั้ง Laptop และมือถือ ภาพอ้างอิงของ requirement คือ `prompts/S__2113554-1.jpg`

- ค้นหาด้วยภาษาไทย เช่น ยิ้ม หัวใจ นิ้วโป้ง หรือ ไทย และเลือกตามหมวดคน/ร่างกาย สัตว์ อาหาร การเดินทาง กิจกรรม วัตถุ สัญลักษณ์ และธง
- เลือกสีผิวจากตัวเลือกข้างช่องค้นหา มีหมวดใช้ล่าสุดที่จำรายการบน browser ของผู้ใช้
- แทรกตรงเคอร์เซอร์หรือแทนเฉพาะข้อความที่ลากเลือก กดหลายตัวต่อกันได้ การเลือกยังไม่ส่ง LINE ให้ตรวจข้อความแล้วกดส่งตามปกติ
- ระหว่างเลื่อนดูอีโมจิ การอัปเดตแชทอัตโนมัติและการเลือกอีโมจิจะไม่รีเซ็ตรายการกลับด้านบน
- กด Esc ปุ่มปิด หรือคลิกนอกแผงเพื่อปิด ข้อความที่พิมพ์ค้างไว้ยังอยู่ เมื่อเปลี่ยนแชทจะปิดแผงพร้อมเปลี่ยน composer ตามลูกค้าที่เลือก
- เมื่อข้อความเกินขีดจำกัด 5,000 หน่วย UTF-16 ของช่องกรอก จะไม่เติมอีโมจิเพิ่มหรือทิ้งข้อความเดิม การส่งและ retry ยังคงใช้ข้อความ Unicode และ request ID ของระบบเดิม

## ชุดข้อมูลและภาพ

ใช้ `emoji-picker-react@5.1.4` แบบโหลดเมื่อเปิดแผง พร้อมชุดข้อมูลภาษาไทยจากแพ็กเกจ มี 1,906 รายการหลัก รวมสีผิวและรูปแบบต่าง ๆ เป็น 3,931 รายการ ตรวจเทียบ URL ภาพทุกรายการกับรายการไฟล์ของ Twemoji 17.0.3 แล้วครบ ชุดข้อมูลค้นหาให้บริการจากแอป ส่วนภาพในแผงโหลดจาก `https://cdn.jsdelivr.net/gh/jdecked/twemoji@17.0.3/assets/svg/` เฉพาะเมื่อเลื่อนมาเห็น โดย URL มีเพียงรหัสอีโมจิ

ภาพในแผงเลือกใช้ Twemoji ชุดเดียวกันบน Laptop และมือถือ การส่งเป็นข้อความ Unicode จึงแสดงรูปร่างตามอุปกรณ์ของผู้รับ ชุดนี้เป็นอีโมจิมาตรฐาน; Genmoji ของ iPhone หรือสติกเกอร์ LINE เป็นเนื้อหาคนละชนิด ผู้ใช้ยังแนบรูปหรือเลือกสติกเกอร์ด้วยเครื่องมือเดิมได้

ภาพ Twemoji โดย Twitter และผู้ร่วมพัฒนา ใช้สัญญาอนุญาต CC-BY-4.0 ไม่มีการแก้ภาพต้นฉบับ เครดิตและข้อความสัญญาอนุญาตอยู่ที่ `frontend/public/emoji-notices.txt` และ `/emoji-notices.txt` บนแอป รวมทั้งระบุเครดิตใน attribute ของแผงเลือก

แหล่งอ้างอิงหลัก: [Emoji Picker React](https://github.com/ealush/emoji-picker-react), [Twemoji 17.0.3](https://github.com/jdecked/twemoji/tree/v17.0.3), [Twemoji artwork license](https://github.com/jdecked/twemoji/blob/v17.0.3/LICENSE-GRAPHICS)

## ไฟล์และการตรวจสอบ

- `frontend/src/components/chat-emoji-picker.tsx` — ชุดข้อมูลภาษาไทย ข้อความ UI ภาพ หมวด สีผิว และรายการล่าสุด
- `frontend/src/components/reply-composer.tsx` — เปิด/ปิดแผง ตำแหน่งเคอร์เซอร์ การแทนข้อความ และการส่งตามปกติ
- `frontend/src/components/reply-composer.css` — ขนาดแผงตามจอ เป้ากด และการแสดงร่วมกับ composer
- `frontend/src/lib/emojis.ts` — URL ภาพที่รองรับ variation selectors/keycaps/ZWJ และการเติมข้อความตามขีดจำกัด
- `frontend/tests/emojis.test.mjs` — การแทนข้อความ Unicode ลำดับอีโมจิหลาย code point ขีดจำกัดข้อความ และ URL กรณีพิเศษ
- `frontend/tests/emoji-picker-render.test.mjs` — ตรวจว่าการอัปเดตแชทและการเลือกอีโมจิใช้ตัวโหลดข้อมูลเดิม เพื่อไม่ให้รายการถูกรีเซ็ต พร้อมตรวจ callback เลือกอีโมจิหลัง render ใหม่
