# เมนูหลังบ้าน Arisa Rental

เจ้าของร้านเปิด **ตั้งค่าร้าน** ได้จากไอคอนเฟืองด้านขวาของการ์ดชื่อร้านในหน้า Home (`#settings`) เพื่อกำหนดเงื่อนไข AI สำหรับออกบิล ดูรูปแบบที่รองรับและขอบเขตการทำงานที่ [เงื่อนไขออกบิลของร้าน](shop-billing-instructions.md)

หน้าหลักหลังเข้าสู่ระบบเป็นภาพรวมร้าน **Arisa Rental** เมนูหลักแบ่งเป็น 3 หน้า:

1. **หน้าหลัก** (`#home`) — ชื่อร้าน บัญชีที่ใช้งาน แชทล่าสุด จำนวนแชทที่โหลดแล้ว แชทยังไม่อ่าน และแชทที่มีร่างออเดอร์แต่ยังไม่ส่ง จำนวนเป็นภาพรวมจากรายการที่โหลดอยู่ ไม่ใช่ยอดรวมทั้งฐานข้อมูล ปุ่มตั้งค่าการแจ้งเตือนข้อความอยู่ในส่วนบัญชีของหน้านี้
2. **รายการแชท** (`#chats`) — รายชื่อลูกค้า ค้นหา เปลี่ยนชื่อ และสถานะยังไม่อ่าน เลือกลูกค้าเพื่อเปิดบทสนทนา
3. **ทีม** (`#team`) — หน้าจัดการพนักงาน คำเชิญ และสิทธิ์เดิม เปิดได้เฉพาะเจ้าของร้านที่มีสิทธิ์จัดการทีม พนักงานและผู้จัดการยังเข้าหน้านี้ไม่ได้ การเปลี่ยนเมนูไม่ได้เพิ่มสิทธิ์ API

บนมือถือ บาร์ด้านล่างเป็นบาร์แคบ ไอคอนและชื่ออยู่ในแถวเดียวกัน เมื่อเปิดแชทหรือออเดอร์ของลูกค้า บาร์จะหายไปและแสดงปุ่มด้านบนเรียงจากซ้ายไปขวา:

- **กลับ** — กลับรายการแชท
- **แชท** — บทสนทนาของลูกค้าที่เลือก (`#chat/<inquiry_id>`)
- **ออเดอร์** — สรุป ร่าง คิว/บิล ประวัติ และ Note ของลูกค้าคนเดียวกัน (`#order/<inquiry_id>`)

การสลับแชทกับออเดอร์ของลูกค้าคนเดิมไม่ล้างข้อความตอบที่ยังไม่ส่งหรือสรุปที่กำลังแก้ ปุ่มย้อนกลับ/ไปข้างหน้าของเบราว์เซอร์และการรีเฟรชลิงก์แชทหรือออเดอร์ยังเลือกหน้าตาม URL เดิม ลิงก์แจ้งเตือนแบบ `?inquiry=<id>` เดิมยังใช้ได้

ข้อความตัวอย่างในรายชื่อและข้อความแชทเพิ่มขึ้น 1px และใช้สีเข้มขึ้น แถบเตือนสีส้มเกี่ยวกับสถานะตัวเชื่อม LINE OA ไม่แสดงรบกวนหน้ารายการแล้ว ระบบยังพยายามซิงก์ตามเดิม ข้อผิดพลาดจากการโหลดข้อมูลและการทำรายการอื่นยังแสดงตามเดิม

แอปยังซ่อนเมนูหลักระหว่างกรอกฟอร์มบนมือถือ และเว้น safe area ด้านล่าง
