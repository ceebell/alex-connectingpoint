# ข้อความด่วนและการ์ดรูปภาพ

คลังนี้เป็นของร้าน/LINE channel ใช้ร่วมกันในทีมและข้ามอุปกรณ์ บัญชีพนักงานที่เข้าใช้หลังบ้านได้สามารถเพิ่ม แก้ไข ลบ และเลือกใช้รายการได้ ไม่ผูกกับลูกค้าคนใดคนหนึ่ง

## ใช้ข้อความด่วน

1. ในหน้าแชท กด **+ → ข้อความด่วน / การ์ด**
2. เลือกแท็บ **ข้อความด่วน → เพิ่มข้อความ** ใส่ชื่อ เช่น `สวัสดี` และข้อความตอบกลับ แล้วบันทึก หรือเลือก **บันทึกข้อความในช่องพิมพ์** เพื่อใช้ข้อความที่กำลังร่างอยู่
3. กลับช่องแชทแล้วพิมพ์ `/` หรือ `/สวัสดี` รายการแนะนำจะแสดงเหนือช่องพิมพ์ ค้นได้ทั้งชื่อและเนื้อหา แสดงได้สูงสุด 8 รายการ ใช้คำค้นเจาะจงขึ้นหรือเปิดคลังเพื่อดูทั้งหมด
4. แตะรายการ หรือใช้ลูกศรขึ้น/ลงและ Enter เพื่อเติมข้อความลงช่องพิมพ์ ตรวจแก้แล้วกดส่งตามปกติ การเลือกรายการไม่ส่งทันที
5. Escape ปิดรายการแนะนำและให้พิมพ์ข้อความที่เริ่มด้วย slash ได้ตามปกติ การมี `/` กลางข้อความหรือลิงก์ไม่เปิดเมนู

## ใช้การ์ดรูปภาพ

1. เปิดคลัง เลือก **การ์ดรูปภาพ → เพิ่มการ์ด** ใส่ชื่อแล้วเลือกรูป เช่น ตารางไซซ์ ขั้นตอนเช่า หรือข้อมูลชำระเงิน
2. บันทึกแล้วกด **ใช้รูปนี้** ระบบเตรียมรูปและแสดงตัวอย่างในช่องตอบกลับ
3. ตรวจรูปแล้วกด **ส่งรูป** รูปส่งผ่าน LINE image message เดิม ไม่ส่งพร้อมข้อความที่พิมพ์ค้างไว้ และไม่ใช่ Flex Message หรือรูปที่ AI สร้าง

รองรับไฟล์ JPG, PNG, WEBP และ GIF ไม่เกิน 40 MB จากเครื่อง โดยแปลงเป็น JPEG แบบภาพนิ่งก่อนเก็บและส่ง รูปเต็มยาวสุด 2048px ไม่เกิน 10 MB และ thumbnail ไม่เกิน 1 MB

รูปในคลังเป็นไฟล์ส่วนกลางที่ไม่หมดอายุตาม LINE media ชั่วคราว เมื่อเลือกใช้จะคัดลอกเป็นรูปของบทสนทนานั้นเพื่อคง snapshot ก่อนส่ง การแก้/ลบการ์ดต้นฉบับภายหลังไม่เปลี่ยนรูปที่เตรียมไว้ การส่งรูปยังต้องมี `PUBLIC_BASE_URL` HTTPS เช่นเดียวกับการส่งรูปปกติ

## การเก็บข้อมูลและสิทธิ์

- MongoDB collection `quick_replies` แยก `shop_id`/`channel_id` มีเวอร์ชัน ผู้สร้าง ผู้แก้ และวันเวลา ลบแบบซ่อนรายการพร้อมลบไฟล์การ์ด ไม่ลบรูปที่คัดลอกเข้าแชทแล้ว
- สร้างรายการใช้ request UUID เพื่อกันบันทึกซ้ำเมื่อ retry แก้ไข/ลบต้องส่ง expected_version เพื่อกันทับข้อมูลจากอีกหน้าต่าง
- รูปคลังอ่านผ่าน API ที่ต้องเข้าสู่ระบบ ไม่ส่ง GridFS ID หรือ token ภายในให้ frontend ไม่เปิด URL ภายนอกจากข้อความหรือรันข้อความเป็น HTML/script
- จัดการคลังและเตรียมรูปไม่เรียกส่ง LINE จนกดส่งจริง การส่งใช้ request ID/LINE retry key เดิมเพื่อกันส่งซ้ำ

API: `GET/POST /api/admin/quick-replies`, `POST /api/admin/quick-replies/{reply}`, `POST .../{reply}/delete`, `GET .../{reply}/image/{variant}`, `POST /api/inquiries/{id}/quick-replies/{reply}/media`

ไฟล์หลัก: `backend/src/{models,db,routes}/quick_replies.rs`, `frontend/src/components/{reply-composer,quick-replies-dialog}.tsx`, `frontend/src/lib/{quick-replies,reply-images}.ts`
