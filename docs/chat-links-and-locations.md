# ลิงก์และตำแหน่งในแชท

- ข้อความลูกค้าและแอดมินที่มี `https://`, `http://` หรือ `www.` แสดงเป็นลิงก์ขีดเส้นใต้ คงข้อความและการขึ้นบรรทัดเดิม
- กดลิงก์แล้วเปิดหน้าต่างยืนยันพร้อมชื่อเว็บไซต์และ URL เต็ม กดยกเลิกหรือ Escape เพื่อกลับแชท กดตกลงเพื่อเปิดแท็บใหม่ โดยเก็บแชทเดิมไว้และไม่ส่ง referrer หรือสิทธิ์เข้าถึงหน้าต่างต้นทาง
- หมุด location จาก LINE แสดงชื่อ ที่อยู่ และพิกัด กดเปิด Google Maps ได้ ใช้พิกัดก่อน หากไม่มีพิกัดที่ถูกต้องจึงค้นหาจากที่อยู่หรือชื่อสถานที่
- ข้อความพิกัดทศนิยม เช่น `13.7563, 100.5018` หรือ `GPS: 0, 0` กดเปิด Maps ได้ ไม่ตีความคู่จำนวนเงินทั่วไปเป็นพิกัด
- ข้อความระบุ `ที่อยู่:`, `ที่อยู่จัดส่ง:`, `สถานที่:` หรือ `Address:` และที่อยู่ไทยที่มีบ้านเลขที่พร้อมส่วนประกอบที่อยู่หลายชนิด จะแสดงปุ่มค้นหาใน Google Maps แยกใต้ข้อความ ไม่แก้ข้อความต้นฉบับ และไม่อ้างว่าเป็นหมุดที่ตรวจสอบแล้ว
- ระบบไม่เรียก geocoding ไม่โหลดแผนที่หรือ preview จากเว็บไซต์ภายนอกก่อนกดตกลง การตรวจที่อยู่เป็น heuristic จึงไม่ครอบคลุมข้อความอิสระทุกแบบ
- URL ยอมรับเฉพาะ HTTP(S) ไม่รัน HTML/JavaScript จากข้อความ ไม่เปิด scheme อื่น URL ที่มีชื่อผู้ใช้/รหัสผ่าน หรืออักขระควบคุม ข้อความที่ถูกยกเลิกไม่แสดงลิงก์

เว็บทั่วไปไม่สามารถบังคับเลือกแอปเบราว์เซอร์เริ่มต้นของระบบได้ `target="_blank"` ขอเปิดแท็บ/หน้าต่างใหม่ในเบราว์เซอร์ที่ใช้อยู่ ส่วน Google Maps อาจเปิดแอป Maps ตามระบบและการตั้งค่าเครื่อง

ข้อมูล location ถูกเก็บใน payload ของ backend เดิม งานนี้เพิ่มชนิดข้อมูลและการแสดงผลใน frontend โดยไม่เพิ่ม API, API key หรือ dependency

ไฟล์หลัก: `frontend/src/components/chat-linked-content.tsx`, `chat-linked-content.css`, `frontend/src/lib/chat-links.ts`, `frontend/tests/chat-links.test.mjs`

เอกสารอ้างอิง: [Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started), [MDN: Window.open](https://developer.mozilla.org/en-US/docs/Web/API/Window/open)
