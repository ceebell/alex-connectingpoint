# รายการโปรดสินค้า

ในแท็บร่างล่าสุด กดดาวบนการ์ดผลค้นหาสินค้าจาก Alex เพื่อบันทึกรุ่น สี และไซซ์นั้นในรายการโปรดของร้าน รายการนี้อยู่ใกล้ช่องค้นหา มีรูป ชื่อ รหัส สี ไซซ์ ราคาแค็ตตาล็อกที่อ่านล่าสุด และช่องกรองรายการ กดดาวซ้ำเพื่อนำออกโดยไม่ลบสินค้าในตะกร้า

รายการโปรดเก็บใน MongoDB collection `product_favorites` แยกตามร้าน ช่อง LINE และสาขา ใช้ร่วมกันระหว่างแอดมินที่มีสิทธิ์สาขานั้น และคงอยู่หลังรีเฟรช เปลี่ยนอุปกรณ์ หรือเลือกลูกค้าคนอื่น สินค้าชื่อ/รหัสเหมือนกันแต่คนละ `product_item_id` เก็บแยกกัน

กดปุ่มบวกข้างรายการเพื่อเพิ่มลงตะกร้าของลูกค้าที่เปิดอยู่ครั้งละ 1 ชิ้น ระบบค้นรหัสและตรวจ product ID ตรงตัวกับสาขาใน Alex ใหม่ แล้วใช้กระบวนการเพิ่มตะกร้าเดิมที่ตรวจราคาอีกครั้ง ไม่ใช้ search ID เก่าหรือราคาในรายการโปรดโดยตรง หากหาไม่พบ Alex ขัดข้อง หรือไม่มีสิทธิ์ จะแสดงข้อผิดพลาดและคงรายการโปรดไว้ แอดมินสามารถโหลดใหม่/ลองใหม่เอง ไม่มีการส่งบิลหรือจองคิวอัตโนมัติ

## API

ทุก endpoint ใช้ระบบแอดมิน/สิทธิ์ทีมเดิม การแก้ไขผ่านเบราว์เซอร์ต้องมี session และ `X-Admin-Request`

| Method | Path | หน้าที่ |
| --- | --- | --- |
| GET | `/api/inquiries/{id}/favorites?branch_id=...` | อ่านรายการโปรดของสาขาที่มีสิทธิ์ |
| POST | `/api/inquiries/{id}/favorites` | บันทึกจาก `{search_id, product_item_id}` ที่เซิร์ฟเวอร์ตรวจแล้วว่าอยู่ในผลค้นหาของลูกค้ารายนี้ |
| DELETE | `/api/inquiries/{id}/favorites/{favorite}` | นำออกจากรายการโปรดของร้าน |
| POST | `/api/inquiries/{id}/favorites/{favorite}/cart` | ตรวจสินค้าและราคาล่าสุดก่อนเพิ่มลงตะกร้าของลูกค้าที่เลือก |

Unique index ใช้ `shop_id/channel_id/branch_id/product_item_id` ป้องกันการบันทึกซ้ำ ไม่มี token ของ Alex หรือข้อมูลลูกค้าเก็บในรายการโปรด

โค้ดหลัก: `frontend/src/components/product-favorites.tsx`, `order-cart.tsx`, `order-cart.css` และ `backend/src/{models,db,routes}/product_favorites.rs`
